# 固定H的研究主线与证据边界

2026-11-07固定H为当前主候选、E为回退。H是相同新D权重上的输出改进，不重新训练CLIP或四适配器。原test.py、train.py及adaptcliplib未改动。

## 固定设置

- 新D第14轮best.pth，seed=10，Visa、BTAD、MPDD、SDD、DTD、part_glass，各1/2/4-shot。
- H图像分数：SH=0.75SE+0.25G0。SE为G0_L1完整最终分数（含25%图最大值），G0为新D VA/TA/PQA原生全局均值。
- H/E定位：固定12.5% RMA局部贡献，经过既有ALIGN及sigma=4平滑。不会用12.5%图最大值重新计算SE。
- 入口：`python .\models_test\test_h.py`；回退E：追加`--mode E`。H→E顺序：`python .\models_test\run_test_h_sequence.py`。
- 参考身份、顺序、查询及历史指纹继续检查；每个数据集/shot独立子进程，退出清理后继续。

## 主线与省略步骤

原A → 新流程三适配器对照 → 完整新D → 输出消融G0_L1 → E → G评分诊断 → H。

G是诊断证据，不是另一套性能方法。A到三适配器是整套训练流程比较；三适配器到新D才是匹配新流程下加入RMA方案的增量。完整新D之后共用同一第14轮权重。

简图省略了直接中间过程：

1. G0_L1到E经过固定比例0/12.5/25/37.5%的源域选择和目标补测、固定图像分数的离线组合，再由E真实推理复现。12.5%有目标探索背景，不能称为源域预先盲选或理论最优。
2. G到H内部先在源域比较lambda 0/.25/.5/.75/1，锁定.25，再做目标离线、真实推理和精简入口回归。.25仅在这一源域网格内较优。
3. beta搜索与F是E的平行备选；源域局部诊断检查背景假设。它们支持研究选择，但不是H计算必需模块。
4. 同权重关闭RMA、其他输出开关是必要辅助对照，不归为参数搜索。旧B/C/新B/旧D等为历史路线探索，不把所有失败尝试都说成最终参数的必要筛选。

## 已有证据与缺口

- 匹配新流程三支对照支持RMA方案整体增量；未证明Top8、学习权重和关系头各自作用，也没有梯度冲突或匹配正确率的直接证据。
- 四开关和双输出能归因到计算路径；不能反推应删除RMA全局训练损失。
- G支持part_glass两路评分存在排序差异；SDD共同训练后的三支损失和ALIGN交互仍未完全解释，H没有改善E定位图。
- 12.5%、beta4及lambda.25的精确最优原因未证明；源域验证集重复用于选轮/选参，目标探索参与了研究方向与局部比例选择，不称独立盲测。
- 只有seed10，不声称统计显著或跨seed稳定；原A只是暂定强论文参照，外部论文同协议比较尚未逐篇核实。
